# Arduino Krita Tool

Another excuse for me to play around with making another hyper specific arduino tool, this time in the form of a macropad that ideally connects via bluetooth.

# Goals

* Connect via bluetooth to an android tablet (could honestly be PC)
* Has a keyboard matrix to allow for a wide variety of shortcuts/keys
* * ex: Ctrl-z, ctrl-shift-z... other artist tools (i don't know them i'm not an artist...)
* potentially: using qmk allow for remapping via remap.io
